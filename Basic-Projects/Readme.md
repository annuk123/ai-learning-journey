By the end of Semester 0, you should be able to answer:

* What is AI?
* What is Machine Learning?

Example:

```

│

├── data/

├── notebooks/

├── models/

├── src/

├── train.py

├── evaluate.py

├── requirements.txt

└── README.md
```

Understand what each folder is for.
