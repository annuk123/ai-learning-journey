# Semester 10 — Research (Ongoing)

## Learn to Read Papers

Every paper:

* Abstract
* Introduction
* Related Work
* Method
* Experiments
* Ablations
* Limitations

Start with classics like:

* AlexNet
* ResNet
* Attention Is All You Need
* BERT
* GPT (original paper)

---

## Learn to Reproduce Papers

* Clone repositories
* Train models
* Compare results
* Debug differences

This is one of the fastest ways to think like a researcher.

# 🏆 Milestones

* **Level 1:** Comfortable Python programmer.
* **Level 2:** Can analyze and visualize real datasets.
* **Level 3:** Can build and evaluate classical ML models.
* **Level 4:** Can implement neural networks and train models with PyTorch.
* **Level 5:** Understands transformers and can build LLM-powered systems.
* **Level 6:** Can read, reproduce, and critique research papers.
* **Level 7:** Conducts original AI experiments and contributes to open-source or publishes research.
